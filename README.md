# 漫阅吧

一个极简的 Android 漫画阅读器，支持图片型 EPUB 漫画，按文件夹分卷连续阅读。

![书柜](docs/screenshots/01-app.jpg)

> 截图为真机书柜界面。当前只添加了两本书，因此第一行第三个位置为空。

## 能做什么

- **按文件夹添加**：点右下角圆形 `+`，选择一个文件夹，文件夹内的 `.epub` 会自动识别为一本书的各卷。
- **书柜一行三本**：封面取 EPUB 声明的封面；文件夹书显示“当前读到的那一卷”的封面，新添加时显示第一卷封面。
- **自然排序、跨卷连读**：卷按文件名中的数字排序（如 `xx卷01`、`xx卷02`），读完一卷自动接下一卷。
- **上下拼接、连续滚动**：阅读页纵向连续排列，上下滑动阅读。
- **左滑返回书柜**：阅读界面没有任何按钮、工具栏或进度条，左滑即可回到书柜。
- **放大局部**：双指缩放、拖动平移查看细节，单击画面还原到默认缩放与位置。
- **进度记忆**：自动记录读到哪个文件、哪一页，重新打开从上次位置继续；文件夹的进度是跨卷累计的整体进度，冷启动会直接进入最后一次在读的漫画。
- **正在读的书置顶**：书柜按最近阅读时间排序。

## 怎么用

1. 在手机文件管理里准备好漫画文件夹，例如 `镇魂街/镇魂街卷01.epub`、`镇魂街卷02.epub`。
2. 打开「漫阅吧」，点右下角 `+`，选择该文件夹，书柜中即出现这本书。
3. 点封面开始阅读，上下滑动翻页；双指放大后可拖动查看局部，单击还原。
4. 阅读中左滑返回书柜；下次打开 App 会继续上次阅读位置。

## 构建

- 最低系统版本：Android 8.0（API 26）
- 构建 release 包：

```powershell
.\gradlew.bat assembleRelease
```

生成的安装包位于 `app/build/outputs/apk/release/app-release.apk`。

仅当工程根目录存在 `keystore.properties` 时才会启用 release 签名；该文件缺失时构建仍可成功，只是产物未签名。
